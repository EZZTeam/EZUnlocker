# ⚡ EZUnlocker — Windows Recovery & Unlock Tool

**EZUnlocker** — легковесная автономная утилита для экстренной реанимации операционных систем Windows 10 и 11 (x64) после заражения винлокерами, шифраторами, скрытыми майнерами и вредоносными скриптами[cite: 8, 10].

Программа работает напрямую через системные WinAPI-вызовы и ветки реестра, обходя типичные блокировки Windows и позволяя вернуть контроль над ПК в один клик[cite: 10, 13].

## ✨ Основные возможности

### 🔓 1. Registry Unlocker (Снятие системных блокировок)
* **Разблокировка Диспетчера задач:** сброс политики `DisableTaskMgr`[cite: 13].
* **Восстановление Редактора реестра:** сброс запрета `DisableRegistryTools`[cite: 13].
* **Доступ к Командной строке:** снятие ограничения `DisableCMD`[cite: 13].
* **Окно «Выполнить»:** удаление блокировки `NoRun`[cite: 13].
* **Восстановление системной оболочки:** сброс параметра `Shell` в `Winlogon` до стандартного значения `explorer.exe` (устраняет черный экран и баннеры вымогателей)[cite: 13].
* **Кнопка «Unlock Everything»:** автоматическое применение всех исправлений реестра одновременно[cite: 13].

### ⚙️ 2. Process Manager (Диспетчер процессов)
* Мониторинг всех запущенных процессов в реальном времени (автообновление каждые 2.5 секунды)[cite: 11].
* Отображение PID, имени, потребления RAM и полного пути к исполняемому файлу[cite: 11].
* Принудительное завершение процессов (`Kill Process`)[cite: 11].
* Быстрый переход к расположению исполняемого файла на диске (`Open Folder`)[cite: 11].
* Встроенная защита критически важных системных служб Windows от случайного закрытия.

### 🚀 3. Startup Manager (Менеджер автозагрузки)
* Сканирование ключевых системных и пользовательских веток запуска: `HKCU\Run`, `HKLM\Run`, `HKLM\RunOnce`[cite: 12].
* Моментальное удаление вредоносных записей и скриптов в один клик (`Remove Entry`)[cite: 12].
* Отслеживание появления новых записей на лету[cite: 12].

### 🧰 4. Tools & Rescue (Инструменты реанимации)
* Быстрый перезапуск Проводника (`Restart Explorer`) при зависании рабочего стола или панели задач[cite: 14].
* Быстрый вызов встроенных инструментов администрирования: `CMD`, `PowerShell`, `Registry Editor`, `MSConfig`[cite: 14].
* Каталог `tools/` для быстрого запуска кастомных утилит прямо из интерфейса программы[cite: 14].

## 📦 Особенности сборки (Portable)

* **Без установки:** программа не требует инсталлятора, не прописывается в системных каталогах и не оставляет мусора[cite: 10].
* **Автономность:** поставляется в виде одного скомпилированного файла `EZUnlocker.exe`, готового к запуску с аварийной флешки[cite: 8].
* **Права администратора:** манифест UAC настроен на автоматический запрос прав суперпользователя для изменения системных параметров.
